# Application outcome inventory

Audit: 8 November 2026; baseline `main` / `origin/main` locally at `0cd05d6`, redesign starting `2dda61a` plus active local work. Source inventory includes all 29 `src/features/*/index.ts` owner boundaries, API service exports, Prisma models, registered MCP tools and the domain guides. The exported service functions and registered tool names in every baseline `src/api/**/*.service.ts` / `ai/skills/*/tools.ts` remain present: **zero missing names**. No feature owner directory has been deleted. This is a useful contract-preservation check, not behavioural proof.

Status vocabulary: **retained** = the real service/forms remain reachable; **redesigned** = a new access path is implemented; **verified** always specifies evidence; **open** = further implementation or acceptance remains. Do not translate “retained” into full acceptance. The atlas is not a feature inventory.
