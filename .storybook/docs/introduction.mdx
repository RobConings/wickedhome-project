# WickedHome component catalogue

| Group | Folder | What it is |
|---|---|---|
| **UI** | `src/components/ui` | shadcn/ui controls: Button, Input, Select, Dialog… |
| **Feature components** | `src/features/<feature>/components` | Everything a feature renders |
| **Screens** | `src/features/<feature>/screens` | Full pages |
| Route | `src/routes` | Loads data, renders one screen. Not in Storybook |

## Using this catalogue

- Use the toolbar to switch **language** (English / Nederlands) and **theme** (light / dark).
- Every story runs inside a router, so links, forms and dialogs behave as they do in the app.
- Stories live in the top-level `stories/` folder (`stories/ui/button.stories.tsx`,
  `stories/features/household/components/habitant-card.stories.tsx`); example data goes in
  `stories/features/<feature>/fixtures.ts`.
